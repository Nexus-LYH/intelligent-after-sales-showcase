## 已实现

沿用FeeGroup纯内核与JdbcFeeGroups/V1，新增V2当前客户报价确认及本地审批请求。Q/C/H/B、永久财务标记及首次触发申请/版本保持原规则；报价/成本/审批基数/客户授权/客户应收和资金账不混用，不增加费用结清关闭门槛。

六个HTTP接口、状态及准确边界见api-quotes-v1.json：授权工单的稳定同故障组、不可变报价/替换明细、当前管理员确认、报价只读及原actor原UUID查询。金额/版本/ID按字符串返回，客户不见内部C/H/B、财务阈值/历史触发。报价改版不继承客户决定；真实成本超过冻结基数须新报价，不自动把差额收作应收。

客户付费报价提交只记录等待客户确认事件，没有内部审批请求；当前客户企业管理员确认后，本地同事务追加确认、审批请求、原结果、审计、outbox及组版本。不收费报价直接记录本地请求。finance_approval_request仅为持久意图，不是approval服务已创建任务或已批准；H仅在可信完成审批事实入账后改变。

原UUID恢复仍须当前资格，原结果查询无写且只能原actor读取。组锁/CAS裁决并发，审计失败整个本地事务回滚。回滚/commit结果不确定不恢复自动提交或继续复用连接。旧quote/确认/费用历史保留，不删除原成本，也不把成本反向纠错当退款。
